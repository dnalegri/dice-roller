# dice-roller
Animated dice roller and status strip widgets for a Vampire: The Masquerade V5 chronicle. Load from jsDelivr:





https://cdn.jsdelivr.net/gh/dnalegri/dice-roller@v1.0.0/roller.js defines VTMCheck(CHECK, STATE)



https://cdn.jsdelivr.net/gh/dnalegri/dice-roller@v1.0.0/status.js defines VTMStatus(STATUS)

Each function renders into an element with id vtm.
